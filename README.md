# Quick Job Apply Autofill

One-click Chrome extension that autofills job application forms (Workday, Greenhouse, Lever, etc.) with your saved profile — name, email, phone, address, job info, CTC, links, summary, cover letter.

Your info is stored only in `chrome.storage.local` in your own browser. Nothing is uploaded anywhere.

## Use it in your browser (Chrome)

1. Clone the repo:
   ```bash
   git clone https://github.com/Pritamawatade/autofill_extension.git
   cd autofill_extension
   ```
2. Open Chrome and go to `chrome://extensions`.
3. Turn on **Developer mode** (toggle, top-right corner).
4. Click **Load unpacked**.
5. Select the cloned `autofill_extension` folder (the one containing `manifest.json`) and click Open/Select.
6. Pin the extension (puzzle icon in toolbar → pin **Quick Job Apply Autofill**).
7. Click the extension icon → fill in your details once → click **Save info**.
8. Open any job application form → click the extension icon → **Start Filling**.
